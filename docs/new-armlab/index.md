For this lab, we will work on a 6-DOF robotic arm and learn how to interact with such systems. We will primarily be working towards building the autonomy for this robot, using computer vision techniques, kinematics and path planning to enable the robot to manipulate various objects.

1. [Setup Guide](/docs/new-armlab/setup-guide) — get your station, codebase and environment running.
2. [Hardware](/docs/new-armlab/hardware) — what is on the station and how it is wired.
3. [Software](/docs/new-armlab/software) — the code you will be editing.
4. [Checkpoints](/docs/new-armlab/checkpoints/) — the graded tasks, in order.
5. [How-to Guide](/docs/new-armlab/how-to-guide/) — reference material you will come back to.
